## About

**HexA8085** is a fully-featured 8085 microprocessor simulator for Android. Write assembly mnemonics, assemble to hex opcodes, step through execution, and inspect registers, flags, and memory - all on your device.

No server, no account required. Your code never leaves your phone.

---

## Features

| Feature | Description |
| --- | --- |
| **Syntax highlighting** | Color-coded mnemonics, registers, numbers, and comments. |
| **Real-time execution** | Step through instructions one at a time with full state inspection. |
| **Register & flag view** | See all registers (A-L, SP, PC) and flags update in real time. |
| **Memory inspector** | View and edit 64KB memory with hex and decimal display. |
| **Code examples** | Built-in examples to get started quickly. |
| **Dark & light themes** | Comfortable coding in any lighting condition. |
| **Offline** | Works fully offline. No internet required. |
